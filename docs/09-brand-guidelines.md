## 2. Logo & Wordmark

### 2.1 Logo Variations

KIKI Agent uses a wordmark-only identity (no icon). The brand is the name set in JetBrains Mono.

**Primary:** `KIKI Agent™` in JetBrains Mono Bold, K.blue (`#005CFF`)
**Inverted:** White on dark backgrounds (`#FFFFFF`)
**Mono:** K.t1 (`#F9FAFB`) on g900 (`#111827`)

### 2.2 Clear Space

Minimum clear space: the height of the "K" character on all sides.

### 2.3 Minimum Size

- Digital: 16px font size minimum
- Print: 12pt font size minimum

### 2.4 Incorrect Usage

- ✗ Never stretch or distort the wordmark
- ✗ Never change the typeface (must be JetBrains Mono)
- ✗ Never use lowercase for "KIKI" (always uppercase)
- ✗ Never remove the ™ symbol
- ✗ Never apply glow or shadow effects

## 5. Tone of Voice

### 5.1 Principles

| Principle | Description |
|-----------|-------------|
| **Precise** | Use exact numbers, not approximations. "38ms" not "~40ms". "R²=0.91" not "very accurate". |
| **Technical** | Assume the reader understands ad tech. Use correct terminology (CAPI, LTV, IVT, SyncBrain). |
| **Confident** | State facts without hyperbole. "KIKI predicts 90-day LTV in 38ms" not "KIKI revolutionises prediction with blistering speed". |
| **Direct** | Short sentences. Active voice. "Bid optimisation becomes a race to the bottom" not "It can be observed that bid optimisation..."

### 5.2 Do & Don't

| Do | Don't |
|----|-------|
| "Your £149 order becomes a £639 signal." | "Unlock the hidden potential of your customer data with our AI-powered platform!" |
| "Six autonomous AI agents execute within your guardrails." | "Our cutting-edge AI agents work tirelessly to optimise your campaigns." |
| "38ms LTV prediction. R²=0.91. 4.29× average uplift." | "Lightning-fast predictions with industry-leading accuracy." |
| KIKI Agent | kiki agent, Kiki Agent, KIKI Agent platform |
| STOREGRILL INC LTD | Storegrill, storegrill inc ltd |

### 5.3 Capitalisation Rules

- KIKI Agent (always uppercase KIKI, capital A for Agent)
- STOREGRILL INC LTD (always uppercase)
- SyncBrain™ (capital S, capital B, ™ on first use)
- CAPI (always uppercase)
- LTV (always uppercase)
- ROAS (always uppercase)
- IoT (always uppercase)
- SaaS (always uppercase)
- UK (always uppercase)

## 6. Document Templates

### 6.1 Business Document Template

**Page setup:**
- A4 (210mm × 297mm)
- Margin: 20mm all sides
- Header: Thin K.blue line at top (1pt), document title in JetBrains Mono Bold 10pt
- Footer: "KIKI Agent™ — STOREGRILL INC LTD | Confidential" in 8pt, centred
- Section headers: K.blue `#005CFF`
- Tables: Alternating row colours (white / K.g850 `#1F2937`)
- Page numbers: Bottom right, 8pt

**Colour scheme for printed documents:**
- Use dark text on white background for printed documents (K.blue for headers, black for body)
- Digital-only documents keep the dark theme (white text on dark background)

### 6.2 Presentation Template (Pitch Deck)

- Dark background (K.void `#030712`)
- White text (K.t1 `#F9FAFB`), K.blue `#005CFF` accents
- JetBrains Mono throughout
- 2px border radius on all graphic elements
- No bullet points — use short statements on slides, expand verbally
- Full-bleed dark slides with accent-colour glow effects
